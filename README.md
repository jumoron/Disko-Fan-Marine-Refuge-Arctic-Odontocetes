Pipeline for multi species (NW, SPW and NBW in _sep) or single species (NW in _feb) click parameters extraction - event_type, UID, sampleDuration, min freq, max freq, amplitude, TOL_16kHz, TOL_25kHz, TOL_40kHz, 
R_16_25, R_25_40, RL_peak, RL_rms, zero crossings, peak frequency, -3 dB and -10 dB central frequency, min/max frequency, and bandwidth - using PAMPal package.
